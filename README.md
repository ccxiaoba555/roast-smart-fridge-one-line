A tiny deterministic program that writes one roast of the smart fridge to `/output/entry.txt`: it emails you a weekly report on your 2am snacking — a snitch with a lightbulb and a superiority complex. One line, 150 characters, one gadget, one sting at the end.

## Run it

```sh
python3 main.py
```

The program checks the roast against the gate (1–160 characters, a single line of UTF-8 text, not blank) and writes it to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
